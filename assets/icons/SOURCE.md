# 程序图标来源

钰宇鼠标连点器使用用户于 2026/11/15 选定的蓝紫双色指针。

- 原图名称：Clicker Mouse Clicker。
- 发布网站及署名：SVG Repo；原页面未列出个人作者，不推测作者身份。
- [原图与 CC0 许可页面](https://www.svgrepo.com/svg/184232/clicker-mouse-clicker)。
- [原始 SVG 下载](https://www.svgrepo.com/download/184232/clicker-mouse-clicker.svg)。
- 许可：CC0 1.0 Universal；完整法律文本保存为 `LICENSE.CC0-1.0.txt`。
- [CC0 官方法律文本](https://creativecommons.org/publicdomain/zero/1.0/legalcode.en)。
- 下载及许可核对日期：2026/11/15。

`cursor.svg` 保留原始形状和配色。`cursor.png` 为 Sharp 栅格化的 512×512 透明 PNG；`mouse.ico` 通过 Pillow 12.1.1 进行格式转换，包含 16、24、32、48、64、128、256 像素尺寸。未重新绘制或改变配色。

运行状态图标 `running.ico` 使用本项目绘制的绿底白色播放三角，包含 16、20、24、32、40、48、64、128、256 像素尺寸。停止时使用原蓝紫指针。
