## 选择安装版或便携版

| 项目 | 安装版 | 便携版 |
| --- | --- | --- |
| 下载文件 | `YuyuMouseClick-v1.2.0-win-x64-setup.exe` | `YuyuMouseClick-v1.2.0-win-x64-portable.zip` |
| 使用方式 | 运行中文向导后从开始菜单启动 | 完整解压到可写目录，运行 `钰宇鼠标连点器.exe` |
| 默认程序目录 | `%LOCALAPPDATA%\Programs\YuyuMouseClick` | 用户选择的解压目录 |
| 配置文件 | `%LOCALAPPDATA%\HQY.MouseClick\settings.json` | EXE 旁的 `data\settings.json` |
| 卸载 | Windows 设置中的应用卸载入口；保留用户配置 | 先退出程序，再自行移除解压目录；需要保留设置时先备份 `data` |

安装版仅面向当前用户安装。安装版与便携版各自读取配置，不自动共享或迁移。首次使用便携版时会创建自己的配置；如需延续已有设置，可在两边程序均退出后备份并复制 `settings.json` 到对应位置。

便携包中的 `portable.flag` 是配置模式标记，请与 EXE 一起保留。移动便携程序时一并移动 `data` 目录，不要直接从 ZIP 预览中运行。两种发行包均附带使用说明、更新日志、图标来源和图标许可。

## 快速使用

1. 设置按键、单击或双击、点击间隔和启动延时，时间单位均为毫秒。
2. 选择跟随鼠标、固定坐标或多位置模式。多位置模式可用“屏幕点选”依次添加位置，右键或 Esc 完成。
3. 设置重复轮数，`0` 表示持续运行。多位置模式完成整个列表算一轮，双击算一次动作。
4. 按 F6 开始或停止；需要紧急停止时按 Ctrl+F8。

| 操作 | 快捷键 |
| --- | --- |
| 开始 / 停止 | 默认 F6，可选择 F9 或 F10 |
| 屏幕取点 | F7 |
| 紧急停止 | 固定 Ctrl+F8 |
| 完成多点选择 | 鼠标右键 / Esc |

Ctrl+F8 被占用时禁止启动，软件不会自动更换紧急停止键。释放冲突后，重新选择开始/停止快捷键以重试注册。关闭主窗口也会先停止任务。

## 校验下载

同时下载 Release 中的 `SHA256SUMS.txt`，在 PowerShell 中计算下载文件的 SHA-256，与清单中的同名条目逐字比较：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\YuyuMouseClick-v1.2.0-win-x64-setup.exe'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\YuyuMouseClick-v1.2.0-win-x64-portable.zip'
```

`release-manifest.json` 记录版本、源码提交和发行产物信息。校验值用于检查下载文件是否与发行清单一致，不等同于数字签名。

## 已知限制

- 本版本尚未数字签名，Windows 可能提示未知发布者或显示 SmartScreen 警告。
- 点击间隔可设为 1～86400000 毫秒，实际节奏受 Windows 调度影响，不保证 1 毫秒精度。
- 本工具执行桌面前台点击，不支持后台点击或操作录制；目标应用是否接收模拟输入由其自身决定。
- 目标应用以管理员身份运行时，连点器可能也需要相同权限。
- 未覆盖所有显示器缩放组合和所有第三方应用或游戏。已有开发阶段功能验收范围见 [验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/v1.2.0/docs/validation-2026-11-15.md)。
