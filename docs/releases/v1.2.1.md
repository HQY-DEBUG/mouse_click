# 钰宇鼠标连点器 v1.2.1

发布日期：2026/11/15。Windows 10/11 x64，包含 .NET 运行时。

## 本次更新

- 点击间隔、启动延时的单位改为 **秒（s）**，支持三位小数，例如 `0.5`、`1.25`、`0.001`。
- 旧设置自动按相同时长显示：原来的 `5000` 毫秒变为 `5.000 s`，无需手动换算。
- 点击间隔范围为 `0.001～86400 s`；启动延时为 `0～3600 s`。步进按钮每次增减 `0.1 s`。
- 内部配置继续保存整数毫秒，兼容原配置；超过三位小数时按三位小数四舍五入。
- 紧急停止仍为 **Ctrl+F8**，多位置循环和其他点击功能保持原有行为。

## 下载与升级

| 版本 | 文件 | 使用方式 |
| --- | --- | --- |
| 安装版 | `YuyuMouseClick-v1.2.1-win-x64-setup.exe` | 退出旧程序后运行，原位升级并保留用户设置 |
| 便携版 | `YuyuMouseClick-v1.2.1-win-x64-portable.zip` | 完整解压到可写目录，运行其中的 EXE |

便携版请保留 `portable.flag`。升级便携版时，先退出旧程序并备份原 `data` 目录，再将其复制到新目录，延续已有设置。安装版设置位置仍为 `%LOCALAPPDATA%\HQY.MouseClick\settings.json`，便携版仍为 EXE 旁的 `data\settings.json`。

四个发行附件包括上述两个包、`SHA256SUMS.txt`、`release-manifest.json`。使用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath '<下载文件路径>'` 与清单核对；来源清单记录构建提交。

本版本未数字签名。界面输入精度为 0.001 s，实际点击节奏仍受 Windows 调度影响，不保证毫秒级实时精度。测试范围见[本版验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/releases/validation-v1.2.1.md)，历史变更见[版本记录](https://github.com/HQY-DEBUG/mouse_click/blob/v1.2.1/CHANGELOG.md)。
