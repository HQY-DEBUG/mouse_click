# 钰宇鼠标连点器 v1.3.0

发布日期：2026/11/16。Windows 10/11 x64，包含 .NET 运行时。

## 本次更新

- 点击主窗口 × 时，默认询问“最小化到托盘”或“退出”；选择“取消”、按 Esc 或关闭询问窗口会保留主窗口。
- 选择“最小化到托盘”后程序继续运行，当前连点任务和全局快捷键保持有效；选择“退出”会先停止连点再结束程序。
- 关闭提示新增“记住我的选择（可在设置中修改）”，下次关闭按保存的选择执行。
- 主窗口和托盘菜单新增“设置”，提供“每次询问”“最小化到系统托盘”“直接退出”三个选项。旧配置升级后默认每次询问。
- 双击托盘图标或选择菜单“显示主窗口”可恢复窗口；菜单同时提供开始或停止连点、设置及退出。托盘菜单“退出”直接结束程序，不受记住的关闭方式影响。
- **Ctrl+F8 紧急停止仍然有效**；被占用时禁止启动，软件不会自动更换停止键。

托盘后台驻留仍会产生实际桌面鼠标输入；它不会向隐藏的目标窗口发送后台点击。使用跟随鼠标模式时仍以当前光标位置为目标。

## 下载与升级

[前往 GitHub Release 下载](https://github.com/HQY-DEBUG/mouse_click/releases/tag/v1.3.0)

| 版本 | 文件 | 使用方式 |
| --- | --- | --- |
| 安装版 | `YuyuMouseClick-v1.3.0-win-x64-setup.exe` | 从托盘菜单退出旧程序后运行，原位升级并保留用户设置 |
| 便携版 | `YuyuMouseClick-v1.3.0-win-x64-portable.zip` | 完整解压到可写目录，运行其中的 EXE |

升级前请确认旧程序已退出；如果主窗口已隐藏，可通过托盘菜单“退出”结束程序。便携版请保留 `portable.flag`。升级便携版时，先退出旧程序并备份原 `data` 目录，再将其复制到新目录，延续已有设置。

安装版设置位置仍为 `%LOCALAPPDATA%\HQY.MouseClick\settings.json`，便携版仍为 EXE 旁的 `data\settings.json`；两种模式各自保存关闭偏好和点击设置。

四个发行附件包括上述两个包、`SHA256SUMS.txt`、`release-manifest.json`。使用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath '<下载文件路径>'` 与清单核对；来源清单记录构建提交。

## 验证与限制

本版已通过核心、隐藏窗体回归，以及真实窗体进入托盘后继续运行和 Ctrl+F8 停止验收；后者使用计数替身，不产生鼠标点击。详见[本版验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/releases/validation-v1.3.0.md)。此前版本的[历史验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/v1.3.0/docs/validation-2026-11-15.md)仅说明当时的真实鼠标点击覆盖范围。

本版本未数字签名。点击间隔和启动延时继续使用秒（s），支持三位小数；实际点击节奏受 Windows 调度影响，不保证毫秒级实时精度。目标应用是否接收模拟输入由其自身决定，目标应用以管理员身份运行时，连点器可能也需要相同权限。

历史变更见[版本记录](https://github.com/HQY-DEBUG/mouse_click/blob/v1.3.0/CHANGELOG.md)。
