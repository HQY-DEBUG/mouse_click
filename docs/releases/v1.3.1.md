# 钰宇鼠标连点器 v1.3.1

发布日期：2026/11/16。Windows 10/11 x64，包含 .NET 运行时。

## 本次更新

- **启动成功后自动最小化到托盘**。点击主窗口“开始连点”、按当前全局快捷键（默认 F6，可选 F9/F10），或使用托盘菜单启动，均采用相同行为。
- 启动失败时保留或恢复主窗口，显示具体原因，包括停止热键不可用、无效坐标、设置保存失败等。
- 已经进入托盘时，可通过当前全局启停快捷键启动、停止或重新开始，无需先恢复主窗口。新增回归覆盖先进入托盘再使用 F6 启动、停止和重启的路径。
- 点击主窗口 × 时仍按关闭偏好处理：“每次询问”“最小化到系统托盘”或“直接退出”。关闭提示中的“记住我的选择”及主窗口、托盘菜单中的“设置”继续可用。
- 双击托盘图标或选择“显示主窗口”可恢复窗口；托盘菜单保留开始或停止连点、设置和退出。退出会先停止任务，再结束程序。
- **Ctrl+F8 紧急停止**和秒单位三位小数输入保持不变。

本轮改动前，跟随鼠标和三点顺序模式的真实热键基线均通过。用户反馈的托盘 F6 无响应暂未复现，原因仍待进一步定位。

托盘后台驻留仍会产生实际桌面鼠标输入，跟随鼠标模式以当前光标位置为目标；程序不向隐藏的目标窗口发送后台点击。

## 下载与升级

[前往 GitHub Release 下载](https://github.com/HQY-DEBUG/mouse_click/releases/tag/v1.3.1)

| 版本 | 文件 | 使用方式 |
| --- | --- | --- |
| 安装版 | `YuyuMouseClick-v1.3.1-win-x64-setup.exe` | 从托盘菜单退出旧程序后运行，原位升级并保留用户设置 |
| 便携版 | `YuyuMouseClick-v1.3.1-win-x64-portable.zip` | 完整解压到可写目录，运行其中的 EXE |

升级前确认旧程序已退出；主窗口隐藏时可通过托盘菜单“退出”结束程序。便携版请保留 `portable.flag`；升级时先退出旧程序并备份原 `data` 目录，再将其复制到新目录，延续已有设置和关闭偏好。

安装版配置仍位于 `%LOCALAPPDATA%\HQY.MouseClick\settings.json`，便携版仍位于 EXE 旁的 `data\settings.json`。两个版本各自读取配置，不自动共享或迁移。

发行附件包含安装包、便携 ZIP、`SHA256SUMS.txt` 和 `release-manifest.json`。使用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath '<下载文件路径>'` 与校验清单核对；来源清单记录构建提交。

## 验证与限制

本版验证范围包括启动自动托盘、先进入托盘后的 F6 启动/停止/重启，以及启动失败恢复主窗口和错误提示。具体执行结果见[本版验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/releases/validation-v1.3.1.md)。

[v1.3.0 验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/releases/validation-v1.3.0.md)与[更早的桌面输入验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/v1.3.0/docs/validation-2026-11-15.md)保留各自版本的覆盖范围，不代表本版重复执行。

本版本未数字签名。点击间隔和启动延时继续使用秒（s），支持三位小数；实际点击节奏受 Windows 调度影响，不保证毫秒级实时精度。目标应用是否接收模拟输入由其自身决定；目标应用以管理员身份运行时，连点器可能也需要相同权限。

历史变更见[版本记录](https://github.com/HQY-DEBUG/mouse_click/blob/v1.3.1/CHANGELOG.md)。
