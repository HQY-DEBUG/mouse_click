# 钰宇鼠标连点器 v1.3.2

版本日期：2026/11/16。支持 Windows 10/11 x64，发行包包含 .NET 运行时。

## 本次更新

- 单击按住 **50 ms** 后抬起；双击为两次 50 ms 按住，中间释放 20 ms，改善对瞬时点击不敏感的目标程序兼容性。
- 停止可取消按住或双击间隔。已发送的按下会对应抬起，取消后不再发送第二次按下，未完成的动作不计入完成数。
- 每次按下前只读检查前台与目标窗口的权限。若权限高于连点器，停止并提示先退出连点器后手动以管理员身份运行，或将目标程序改为普通权限；不会自动提权。
- 启停键和 Ctrl+F8 增加 10 ms 按键状态采样，并与原生热键消息去重。快捷键仍须注册成功；保留冲突拦截和 Ctrl+F8 注册失败禁止启动，F7 取点仍走原生热键。
- 保留秒单位三位小数、启动自动托盘、关闭询问与记住偏好，以及托盘恢复、启停、设置和退出。

**点击间隔仍指一次动作完成后的等待时间。** 设置 3 s 时，相邻单击的起点间隔约为 3.05 s，相邻双击约为 3.12 s，另有系统调度开销。输入框允许的 0.001 s 不表示完整点击能在 1 ms 内完成。

## 已验证范围与限制

最终构建为 0 警告、0 错误，核心测试 25/25，默认 Windows、托盘和完整桌面回归均通过。四个自有真实窗口的两轮输入共 8/8 顺序和落点正确；要求按住至少 30 ms 的接收目标由旧实现的 0/8 提升至 8/8。双击首次按下后取消得到 1 次按下、1 次抬起、0 个完整动作和 0 轮。

这些结果来自自有测试窗口；四窗口专项为缩短测试使用 150 ms 动作间隔，不等同于用户四个游戏、3 s 间隔的完整业务实测。另用四点、3 s 间隔和假鼠标输出验证了托盘 F6 停止与重启、Ctrl+F8 取消，每次停止后 3300 ms 无新增输出。

独立 `NOHOTKEYS` 环境中，保持 100 ms 的 F6 和 Ctrl+F8 已通过状态采样正确派发，原生通道恢复后也未重复派发。同批次 0 ms 瞬时按下/抬起仍未被采样捕获；尚未证明用户游戏采用 `NOHOTKEYS`。

完整结果见[本版验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/releases/validation-v1.3.2.md)，事实与限制见[输入兼容性诊断](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/diagnostics/2026-11-16-input-compatibility.md)。

托盘驻留仍使用实际桌面鼠标输入，不提供后台窗口点击。本版本未数字签名，实际节奏受 Windows 调度影响，目标应用是否接受输入由其自身决定。
