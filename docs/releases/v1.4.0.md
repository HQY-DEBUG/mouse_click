# 钰宇鼠标连点器 v1.4.0

2026/11/23，适用于 Windows 10/11 x64。

开始连点后，主窗口会自动收起。托盘中的绿色播放图标表示“连点中”，蓝紫指针表示“已停止”。将鼠标停在图标上也能读到当前状态。手动停止、按 Ctrl+F8 紧急停止或完成指定轮数后，主窗口会自动显示本次动作数和轮数。

在“全局开始 / 停止快捷键”中可以选择 F8。单按 F8 开始，再按一次停止。Ctrl+F8 始终只用于紧急停止。已有用户会沿用保存的快捷键，新安装默认 F6。

安装版和便携版主程序都默认请求管理员权限。Windows 显示用户账户控制提示时，确认后即可打开。
