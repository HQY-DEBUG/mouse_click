# 钰宇鼠标连点器 v1.4.1

2026/11/23，适用于 Windows 10/11 x64。

选择“固定一个位置”时，点击 X、Y 旁的“选点”或按 F7，再点击屏幕上的目标即可设置坐标。选择“多个位置顺序循环”时，在列表上方输入 X 和 Y，点击“添加坐标”即可追加一行。也可以按 F7 在屏幕上依次点选多个位置。

在列表中按住 Ctrl 点击可选择不相邻的行，按住 Shift 点击可选择一段连续的行。点击“上移”或“下移”会一起移动选中的坐标，并保留它们的相对顺序。点击“移除”后，列表会选中首个被移除位置之后的第一条剩余坐标。如果从该位置一直删到末尾，则选中上一条。删空列表时没有选中项。
