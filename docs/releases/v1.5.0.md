# 钰宇鼠标连点器 v1.5.0

2026/11/23，适用于 Windows 10/11 x64。

新版采用石墨深色和蓝紫高亮。左侧设置点击方式和时间，右侧编辑目标，窗口底部可以查看运行统计并开始或停止连点。

多点列表用蓝紫色标出选中行。按住 Ctrl 可以选中不相邻的坐标，按住 Shift 可以连续选取。固定位置模式会在显示器示意图中标出输入的位置，坐标超出屏幕时会显示提示。

安装版和便携版均可读取当前 Windows 用户目录中的自选 JPEG 背景。发行包默认使用石墨主题。

| 发行版 | 下载与使用 |
| --- | --- |
| 安装版 | 从系统托盘退出旧版本后，运行[安装程序](https://github.com/HQY-DEBUG/mouse_click/releases/download/v1.5.0/YuyuMouseClick-v1.5.0-win-x64-setup.exe)升级。 |
| 便携版 | 将[便携压缩包](https://github.com/HQY-DEBUG/mouse_click/releases/download/v1.5.0/YuyuMouseClick-v1.5.0-win-x64-portable.zip)完整解压到可写目录，打开其中的主程序。旧版便携设置保存在 `data` 目录。 |

发行附件提供 SHA-256 摘要和源码提交。[验证记录](https://github.com/HQY-DEBUG/mouse_click/blob/main/docs/releases/validation-v1.5.0.md)
