# 安装版与便携版发行计划

**目标：** 将钰宇鼠标连点器 v1.2.0 作为首个正式 GitHub Release，交付 Windows x64 安装 EXE 和便携 ZIP，并保留可追溯版本记录。

**方案：** 复用现有 .NET 自包含发布；Inno Setup 6.7.4 生成当前用户中文安装向导，便携包通过 `portable.flag` 将配置保存在随行 `data` 目录。统一版本使用 `version.props`，不引入 CI 或改变点击逻辑。该选择是本次执行采用的常规发行方案。

**约束：** 中文名称和蓝紫图标保持；紧急停止 Ctrl+F8；旧配置位置兼容；不删除用户配置；每个完成的小进度独立验证、commit、push；不覆盖已经发布的版本附件。

## 执行顺序

- [x] 新增便携配置路径与隔离测试，保留安装版和显式配置路径行为。
- [x] 新增统一版本、安装脚本、发行脚本，输出安装版、便携版、SHA256SUMS 和来源清单。
- [x] 补充 CHANGELOG、发行说明、维护指南和 README 下载入口。
- [x] 运行核心与 Windows 非输入测试，核对包内容、版本和哈希；验证便携启动/配置、当前用户安装及同版本重装。
- [x] 独立审查发行改动，记录实际证据；提交推送后构建对应提交的最终附件。
- [x] 创建 v1.2.0 标签和 GitHub Release，上传并下载复核两种包与校验文件。

## 验收重点

- 便携配置必须随目录携带，不能访问或覆盖已有安装版配置。
- 安装必须提供开始菜单、可选桌面快捷方式、卸载入口；保留用户配置。
- ZIP、安装包、程序文件版本、更新日志与 Git 标签必须一致。
- 发行构建只从干净工作区生成，并记录完整源码提交；同版本输出目录存在时拒绝覆盖。
- 安装和启动验收不产生桌面自动点击；此前真实输入验证记录保留，不冒充本轮重复实测。

## 选择记录

使用当前用户安装以避免额外提权；固定 AppId 支持后续原位升级。便携版与安装版不自动复制彼此配置，以免覆盖已有设置。首次正式发行定为 v1.2.0，既有 v1.0.0/v1.1.0 仅记录内部开发历史，不补造已发行标签。
