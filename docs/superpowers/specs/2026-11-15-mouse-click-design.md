# 鼠标连点器设计

## 目标和约束

为用户编写可直接运行的 Windows 中文鼠标连点器，源码位于 E:\myfile\mouse，并持续上传 HQY-DEBUG/mouse_click。每个小进度独立 commit 并 push。禁止访问 SL2_100* 和 sl2_100* 相关内容。新程序不覆盖现有鼠大侠或其他连点器的文件及配置。

## 功能

1. 左/右/中键；单击或双击。
2. 点击间隔 1～86400000 毫秒；启动延时 0～3600000 毫秒；轮数 0 表示持续，正整数表示限定轮数。
3. 跟随当前鼠标、固定坐标、多位置顺序循环三种模式。
4. 多位置通过屏幕点选连续添加，右键或 Esc 完成选择；坐标列表支持手工添加、删除、上移和下移。坐标数量由用户添加的项目数决定。
5. 每轮遍历所有坐标；间隔应用于相邻动作，包括轮次边界；双击算一个动作，内部发送两次按下/抬起。
6. 默认 F6 启停（可改为 F9/F10）、F7 取点、F8 紧急停止。快捷键被其他程序占用时明确提示，不伪装注册成功。只有紧急停止可用时才允许开始。
7. 显示动作次数、完整轮数与运行状态。停止等待正在执行的单次输入结束，停止完成后不继续发送。
8. 设置保存在 %LOCALAPPDATA%\HQY.MouseClick\settings.json。读取坏配置时提示，保留原文件；保存时完整校验。

## 方案选择

- 采用 C# / .NET 10 / Windows Forms：本机已有 SDK，可调用 Windows 原生输入及热键 API，发布自包含 EXE。
- Python GUI：开发方便，但打包需要额外工具，运行依赖更复杂。
- Web/Electron：需要额外运行时与原生输入桥接，本任务无需网页能力。

技术方案由实现者根据现有环境选择。源代码只使用 .NET 标准库和 Windows API，不引入第三方运行依赖。

## 结构

- src/MouseClick.Core：设置、校验、可取消的循环执行器、配置读写。
- src/MouseClick.App：中文界面、屏幕取点、SendInput、全局快捷键。
- tests/MouseClick.Tests：核心行为验证，可选本地窗口输入集成验证。
- scripts：验证和发布入口。
- artifacts：忽略的本机构建和可运行产物。

## 验收与边界

验证多点顺序和轮数、停止/取消、无效参数、输入错误、配置回读；编译并发布，使用受控测试窗口验证实际点击和快捷键。桌面点击模拟受 Windows 权限和目标软件支持影响，不实现后台窗口注入、游戏反检测或录制宏。Windows API 行为参考微软官方 SendInput 与 RegisterHotKey 文档。
